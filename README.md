# Debzane Concept Teleprompter

100% Free Professional Studio Teleprompter for Web & Android.
Built for **Debzane Concepts** by **Sylvester Oga Ogaji** (Powered by **JV Impact Initiative**).

## ✨ Features
- Ultra-smooth subpixel velocity scrolling
- Horizontal mirror (for glass beam splitter teleprompter rigs) & Vertical flip
- Screen keep awake (WakeLock API)
- Offline-first script storage (localStorage)
- File Import (.txt, .md, .json) and Export (.txt)
- Bluetooth foot pedal & clicker shortcut support (Space, Up, Down, R, M, F)
- Integrated community feedback & donation channels (Naira, USD, GBP)
- Android App ready with Capacitor
